# bit-flip

Research workspace for offline reproduction and causality-constrained extension
of ONEFLIP. The vendored `official-oneflip/` source originated from
[OneFlipBackdoor/OneFlip](https://github.com/OneFlipBackdoor/OneFlip) commit
`340bcff6dbfa265f4ba3b41b9c652e09e5fe6c3c` and includes local reproducibility
and portability changes.

See `official-oneflip/CAUSALONEFLIP_EXPERIMENT.md` for the Ubuntu and Windows
experiment workflow. Model files, datasets, local environments, and large trial
artifacts stay local by design and are excluded from Git.
